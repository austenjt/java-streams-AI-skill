## Java Streams

Any task involving `java.util.stream` — writing, reviewing, debugging, or modernizing stream code — should follow the guidance in this repo's Java Streams skill:

- [`.claude/skills/java-streams/SKILL.md`](.claude/skills/java-streams/SKILL.md) and the files under `.claude/skills/java-streams/references/` (a symlink into [`plugins/java-streams-plugin/skills/java-streams/`](plugins/java-streams-plugin/skills/java-streams/), the canonical copy).

Both paths resolve to the same content — read either one directly, it's plain markdown regardless of which agent/tool is operating in this repo.

This repo is also a plugin marketplace distributing that same skill for installation elsewhere — see [README.md](README.md) for install instructions (Claude Code and GitHub Copilot CLI).
